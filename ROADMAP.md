# PU Hero Clash — Ultimate-feel roadmap

Saved list of everything we want to make the game feel more like Smash Ultimate.
`[x]` = done, `[~]` = partly there, `[ ]` = to do.

## Round 1 (done)
- [x] Limb hurtboxes (already in), weapons and weapon props now never hittable (disjoint)
- [x] 1v1 damage x1.2 when exactly two fighters remain; aim for KOs around 140%
- [x] Multi-hits hold the target to the finisher; down airs get a landing hit
- [x] Wide glowing swing trails on every melee move; hit sparks that point along the launch
- [x] Up-B snaps to the ledge while still rising; landing helpless / out of up-B has real lag
- [x] Footstools pin grounded rivals and spike airborne ones (footstool itself was already in); grab mash-out (pummel was already in); teetering and walking stops at edges

## Round 2 (done): hitboxes, knockback, combos, movement

## Hitboxes and hurtboxes
- [x] True trades: two attacks that meet on the same frame both connect (grounded clanks were already in)
- [x] Late hits on aerials and smashes (weaker tail of the active frames); weapon tippers on forward tilt and forward smash
- [x] Swept hitboxes so fast attacks can't pass through a target between frames

## Knockback and damage
- [x] Launch speed: 25% faster start, harder slowdown, same travel
- [x] Stale moves: checked, already uses Ultimate's 9-slot values

## Combos
- [x] Jab 1-2-3 holds the rival (83/83 fighters connect)
- [x] Holding A runs the jab string; fast-jab fighters loop a rapid jab and finish on release
- [x] Up throw at low % leaves the rival airborne and in hitstun for a follow-up (down throws are each fighter's unique throw)
- [x] Heavy fighters' neutral airs also get a landing hit

## Movement
- [x] Directional air dodge with landing lag: checked, already in
- [x] Crouch cancel
- [x] Initial dash bursts at run speed or faster (traction per fighter was already in)

## Round 3 (done): ledge, shield and grabs, hit-feel

## Ledge and recovery
- [x] 2-frame punish: ledge invincibility starts 2 frames after the grab (ledge trump was already in)
- [x] Recovery hitboxes: checked. 64 of 80 up-Bs hit; the rest are teleports or flights (or have their own hit code), which matches Ultimate
- [x] Ledge climb: last frames punishable, slower from 100%

## Shield and grabs
- [x] Shield stun and pushback scale with damage: checked, already in
- [x] Whiffed grabs cost lag (standing +4, dash +10, pivot +12)
- [x] Shield break stun shorter at high damage, and you can mash out

## Graphics and hit-feel
- [x] Screen shake grows with launch speed (KO shake/zoom was already in)
- [x] Damage % shake and colour: checked, already in
- [x] Smash charge flashes and glows, with a burst at full charge
- [x] Star KOs and screen KOs on some top KOs (blast-zone burst was already in)

## Round 4 (done): Ultimate feel, part 2
- [x] Hitlag shake: the fighter who was hit shakes through the freeze; the attacker trembles slightly
- [x] Shield pokes: hits on a body part outside a shrunken or tilted shield go through
- [x] Match-ending hit: longer freeze, darker background with speed lines before GAME! (final-stock zoom was already in)
- [x] Short-hop aerials at 0.85x damage: checked, already in
- [x] Jump + attack together = short-hop aerial: checked, already in
- [x] Shield + attack grabs from idle, walk, run (dash grab) and crouch, and is an air grab in the air: checked, already in
- [x] Hit sounds in tiers: light / medium / heavy / KO crunch (synthesized)
- [x] Hit sparks and sounds by family: slash, fire, shock, ice, water, poison, dark, holy (blunt keeps the classic spark)
- [x] Heroic Orb (original design): rule Heroic Finale = METER / HEROIC ORB / BOTH / OFF; CPUs chase it
- [x] Items: Grab + direction throws any held item (flick = smash throw), Z-drop in the air, catch thrown items with A
- [x] Training: launch line after each hit (red where it would KO)
- [x] Training: frame advantage on hit and on shield
- [x] Training: 1/2 and 1/4 speed (pause menu)

## Round 5: next up
- [x] Balance pass 1 and 2 done. Pass 2 (4,000-match run, outliers re-checked at 150 matches): nerfed Emi, Riku, Tenmetsu, Maya, Soran, Ichigo; buffed Makiko, Ali, Gomi, Maho, Takeshi, Bryson, Shuko, Sata. Everyone re-tested now sits about 40-62%. Shuko and Sata are still the lowest (about 40%): next candidates if a pass 3 happens
- [x] Smarter CPUs at every level: no deliberate mistakes; ledge trapping, ledge-option reads, off-stage edge-guards, recovery mix-ups, Makiko sleep setups (level = reaction speed and consistency)
- [ ] Classic mode: a themed six-match route per fighter with its own opponents and stages, a boss, and a difficulty setting
- [x] Results screen with stats: KOs, falls, self-destructs, damage dealt / taken, longest combo, plus Smash-style awards (19 kinds, every player gets at least one)
- [ ] Controls settings: button remapping, tap jump on/off, right stick tilts or smashes (tilts by default), shield options (check what exists)
- [x] Gameplay trailer: the World Premiere trailer (204 s, cut to the theme song)
- [ ] Tune the recent feel changes from playtest feedback (hit sounds, shake, launch speed, edge stops)
