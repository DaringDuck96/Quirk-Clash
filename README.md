# PU Quirk Clash

A 2D pixel platform fighter starring 39 ability students, for 1 to 4 players (keyboard or controllers).

Play it: open `index.html` in Chrome or Edge, or visit this repo's GitHub Pages site.

## Install as an app
Open the GitHub Pages site in Chrome or Edge, click the install icon at the right end of the address bar (or menu > Cast, save and share > Install page as app), and it gets its own window, desktop icon and Start menu / Dock entry. After the first visit it also works offline.

## Modes
- **Fight:** 1 to 4 players or CPUs, free-for-all on 11 stages.
- **Survival:** up to 4 players (CPU slots fight on your side) hold a fortress against endless ninja waves.
- **Training:** one player against a training dummy, with a combo counter and dummy options in the pause menu.

## Controllers
Press any button on a controller to get a pointer. Move it with the left stick, press **A** to select and **B** to go back. **X** adds a CPU, **Y** changes CPU level, **+ / Start** moves on.

In battle: A attack, B special, X/Y or stick-up jump, ZL/ZR shield, L/R grab, right stick smash attacks, D-pad taunt, + pause.
